# Fikeya contributors

Fikeya separates original product work from the Code OSS foundation it builds on.

- **Ajnas N B (`AjnasNB`)** - founder, maintainer, and author of the Fikeya product layer, runtime, desktop integration, public site, release tooling, and project documentation.

## Review

- **Cognifyr (`cognifyrdotco`)** - repository collaborator and independent pull-request reviewer. Review activity is not presented as code authorship.

## Upstream foundation

Fikeya Desktop is built on Code OSS. The thousands of upstream contributors retain their original authorship and copyright records in Git history, `ThirdPartyNotices.txt`, and the upstream project. Fikeya does not relabel upstream work as Fikeya-authored work.

GitHub currently attributes Fikeya-specific repository contributions to `AjnasNB`. This file will be updated as additional people contribute code, documentation, design, testing, security work, or translations.
