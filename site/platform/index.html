The Fikeya platform

One product.
Composable foundations.

Fikeya is the customer-facing product for governed AI-agent work. Maqam, Qarinah, Cockroach Browser, and Cockroach Crawler are its separately versioned components. Their open-source packages, licenses, and technical documentation remain available.

Discuss a team pilotEvaluate locally

Governance component

Maqam

Policy before dispatch, exact one-use approvals, and execution receipts for registered tool calls. Fikeya's enterprise control-plane work builds on these governance concepts. The public TypeScript package and private enterprise service have different deployment boundaries.

Use it forRegistering agent tools, evaluating policy, and binding approval to exact input
Integration boundaryOnly actions routed through the registered boundary are governed
DocumentationMaqam technical docs · Source and license

Project-context component

Qarinah

Select bounded, cited project evidence instead of replaying a complete history. Fikeya exposes context availability and source references so that missing context remains visible.

Use it forProject memory, evidence-linked retrieval, and bounded context packs
Measurement boundaryContext-size reductions do not establish model quality or whole-task savings
DocumentationQarinah technical docs · Source and license

Browser component

Cockroach Browser

A control point for multiple browser-engine lanes. Select an engine, inspect its installed capabilities, and scope browser work to allowed origins. Engine capabilities differ; an unsupported capability is reported explicitly.

Fikeya connectionThe reviewed MCP preset observes sessions and proposes actions; direct execution requires a separate governed dispatch connection
Memory boundaryThe published 28.25 MiB result is an Obscura non-visual fixture, not Desktop or all browser engines
DocumentationFikeya integration guide · Source and license

Web-discovery component

Cockroach Crawler

Scoped web discovery and source collection for agent workflows. Keep crawl permissions, budgets, and retrieved content separate from the authority to act.

Use it forCollecting sources within an explicitly configured crawl scope
Installation boundaryExternal tool executables are installed separately and explicitly enabled in Fikeya
DocumentationCrawler documentation, source, and license
