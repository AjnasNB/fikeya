Verify before installing

Checksums and provenance are available. Trusted signing is not yet complete.

The beta release includes SHA-256 verification files and GitHub build provenance. The current Windows installer is not Authenticode-signed, so Windows can show an unknown-publisher warning.

Do not treat publisher text inside installer metadata as a digital signature. Fikeya has applied to the SignPath Foundation open-source program; no artifact is described as SignPath-signed while that application is pending.
