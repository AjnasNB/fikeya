Release trust

Sign the artifact that the protected build produced.

Fikeya has applied for the SignPath Foundation open-source program. The current beta-1 Windows installer remains unsigned and can show an unknown-publisher warning.

On this pageStatusRolesControlsUpdates and removal
01Status

No current artifact is claimed as SignPath-signed.

The application is pending. If Fikeya is accepted, eligible release and download pages will carry the required attribution:

Free code signing provided by SignPath.io, certificate by SignPath Foundation

A release is described as signed only when its public verification manifest reports a valid signature and timestamp for the exact downloadable bytes.

02Roles

Source review and signing approval are separate.

  • Authors propose changes through pull requests.
  • Reviewers with repository write access review the exact source diff and required checks. The current independent reviewer is cognifyrdotco.
  • Approver Ajnas N B manually approves the exact signing request only after source review and release verification pass.
03Controls

Protected source, reproducible identity, manual release approval.

  1. Protected tag.

    The release tag resolves to reviewed source in AjnasNB/fikeya.

  2. Automated build.

    GitHub Actions builds the installer and packages from that revision.

  3. Exact signing request.

    The final artifact is submitted to the configured service. Fikeya signs only its own binaries.

  4. Manual approval.

    The approver checks the source revision, workflow, artifact identity, and review before signing.

  5. Verification.

    Signature, timestamp, digest, provenance, and manifest must agree before publishing.

Signing credentials and certificate material are never stored in the repository.

04Updates

No silent unsigned update.

The Desktop update feed remains disabled until Fikeya can verify a signed release manifest. Users can remove the VS Code extension through the host extension manager, uninstall Fikeya Desktop through the operating system, and delete local Fikeya/Qarinah state after exporting evidence they want to retain.
