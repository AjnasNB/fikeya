Privacy policy · 26 August 2026

Your project stays local until you choose a provider call.

Fikeya is a local-first editor, extension, and CLI. It does not enable product telemetry by default and does not sell personal data.

On this pageLocal dataProvider transfersRetention and deletionContact
01Local data

Workspace data remains on the device.

Fikeya stores bounded configuration, conversation history when workspace history is enabled, usage receipts, plans, approvals, and Qarinah project evidence in local application or workspace storage. Provider credentials are stored in the operating-system credential vault and are not written into project files.

Fikeya does not collect product analytics, advertising identifiers, browsing history, or hidden model reasoning by default.

02Provider transfers

A configured model provider receives an authorized request.

When a user selects a network provider and confirms a turn, Fikeya sends the prompt, selected bounded project context, conversation history required for that turn, and provider configuration needed to execute the request. The provider processes that data under its own agreement and privacy policy. Fikeya does not proxy or retain the provider request on a Fikeya-operated cloud service.

Loopback providers such as a local Ollama instance can operate without sending project content to an external model provider. Tool and connector network access remains separately controlled.

03Retention

Users control local retention and deletion.

Conversation history is bounded and can be cleared from Fikeya Chat. A workspace can disable retained chat history. Uninstalling the extension or Desktop removes the application but may leave user-owned project evidence so it is not destroyed unexpectedly.

To remove retained project data, export anything that must be kept, close Fikeya, and delete the project's .fikeya and opted-in .qarinah state. Remove provider credentials through Fikeya Settings or the operating-system credential manager. Provider-side deletion requests must be made to the provider that processed the request.
