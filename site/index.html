Privacy and control

Local secrets. Scoped tools. Inspectable actions.

The public workflow does not require a tracking account. You choose the provider, workspace, and actions the agent can use.

Credential isolation

API keys are stored by the operating system credential service. Project files contain references, never raw secrets.

Exact command boundaries

The broker accepts an argument vector, stays dry-run by default, enforces an executable allowlist, and refuses working directories outside the initialized workspace.

One-use approval

A short-lived token is bound to the canonical executable, arguments, directory, and environment keys. A changed request invalidates it.

Typed usage fields

Provider-reported usage, tokenizer measurements, and local estimates use distinct receipt fields instead of being presented as the same number.

No site telemetry

This site makes no analytics or advertising requests. Product telemetry is not enabled by this website.

Connector restraint

Browser and crawler presets are reviewed, digest-bound, and disabled by default. Their separate executables do not run merely because a workspace opens.
